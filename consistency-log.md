## 2026-06-07 — The Mac Mini M1 Is So Close To The Perfect Homelab Server
- Bobby tested a used Mac Mini M1 bought for about £220.
- The unit discussed had 8GB RAM and a 256GB SSD.
- Bobby ran about 8 to 10 Docker containers on macOS without performance issues.
- Bobby’s core objection is not raw performance but the compromise between Docker on macOS and Thunderbolt support on Fedora Linux.
- Fedora Linux was preferred for cleaner Docker networking, custom IP handling, and a more natural server setup.
- Thunderbolt support on the Fedora/Asahi route was the dealbreaker for the external-storage and NAS angle.
